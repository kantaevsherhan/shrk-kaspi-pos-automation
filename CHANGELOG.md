# Изменения

## Go + Vue

- Сервер переписан на Go, веб-панель — на Vue 3 и Element Plus.
- Удалён SQLite-журнал запросов. История завершённых операций читается из Kaspi.
- Сохранены Bearer-доступ, SMS-вход, счета, QR, история, возвраты и подписанные вебхуки с повторами.
- Docker Compose собирает интерфейс и Go-сервис в одном образе.
