## Промпт баннера

Режим: встроенный imagegen, создание нового изображения, непрозрачный фон.

```text
Use case: ads-marketing. Asset type: a finished hero banner for a GitHub README. Create a polished ultra-wide 3:1 landscape banner for the open-source project Kaspi POS Console. Style: restrained premium fintech editorial design, soft off-white and very light cool gray background, charcoal typography, a few coral-red accents (#ef5350) and small mint details, matching a modern light payment dashboard. Composition: generous safe margins, the left half is clean typography, the right half contains a tasteful sculptural 3D illustration of a white rounded QR payment tile, a slim invoice card and a small mint confirmation check, with soft ambient shadows and a pale coral circular accent behind them. The decorative QR-like motif must be nonfunctional. The illustration must not depict a fake dashboard or a bank advertisement. Set the exact large heading 'Kaspi POS Console' in a crisp modern sans-serif font and the exact smaller Russian subtitle 'Платежи под контролем'. Render both lines accurately and legibly; no other text. Calm, spacious, professional composition readable at GitHub content width. No official Kaspi logo, no people, no device mockups, no watermark, no neon, no dark background. Opaque background.
```
