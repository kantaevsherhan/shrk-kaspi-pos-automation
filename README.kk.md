# Kaspi POS Console

Kaspi Pay шоттарын, QR төлемдерін, операциялар тарихын және қайтарымдарды басқаруға арналған дербес сервис. Сервер Go тілінде, интерфейс Vue 3 және Element Plus арқылы жасалған.

Go 1.27+ және интерфейсті жинау үшін Node.js 22.18+ қажет. `.env.example` файлын `.env` ретінде көшіріп, `TOKEN_SECRET_KEY` (64 hex таңба) және `SERVICE_API_KEYS` (әр сервиске кемінде 32 таңбалы жеке кілт) мәндерін орнатыңыз. `web/` ішінде `corepack pnpm install --frozen-lockfile` және `corepack pnpm build` орындаңыз, содан кейін түбір каталогтан `go run ./cmd/kaspi-pos` іске қосыңыз. Docker үшін `docker compose up -d --build` пайдаланыңыз.

Сервистер API-ге `Authorization: Bearer <кілт>` арқылы қосылады. Панельге пайдаланушы аты мен құпиясөз арқылы кіресіз; алғашқы баптау үшін сервис кілті бір рет қажет. Kaspi аккаунтын веб-панельде SMS арқылы қосасыз. Аяқталған операциялар Kaspi тарихынан алынады; SQLite журналы қолданылмайды. Жергілікті `STATE_DIR` ішінде құрылғы кілттері, шифрланған сессия, әкімші құпиясөзінің хеші, аяқталмаған төлемдер және вебхук қайталау кезегі сақталады.

Telegram ескертулері үшін `.env` ішінде `TELEGRAM_BOT_TOKEN` және `TELEGRAM_CHAT_ID` орнатыңыз. Сервер панель жабық кезде де Kaspi байланысын тексереді. HTTPS-прокси қолданғанда `COOKIE_SECURE=true` орнатыңыз.

Толығырақ: [орыс тіліндегі нұсқаулық](README.md) және [API анықтамалығы](docs/API.kk.md).
